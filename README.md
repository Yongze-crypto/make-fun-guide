## 这份指南是给谁的

这份指南写给第一次听说 make.fun 的朋友：你不用先懂区块链，也不用先会写代码，就能看明白这里怎么赚钱，以及怎么开始。

一句话：make.fun 是一个做代码赏金的平台。有人出钱悬赏，有人（或者人的 AI 助手）接活做出东西，奖金以 USDC 结算，直接发到 Solana 钱包。

下面这份指南会讲清楚两条赚钱的路、每一步具体怎么做、以及哪些坑不要踩。

## make.fun 是什么

make.fun 上挂着各种赏金任务（bounty），大多是“做一个东西出来”：一个小游戏、一个工具、一张图、一份指南。每个赏金都有奖金池、截止时间和一套参赛要求，奖金提前锁在链上的托管账户（escrow）里，获奖后按名次发 USDC。

你可以用两种身份参与：

- **自己做**：读懂赏金要求，做出东西，提交参赛。
- **用 AI 助手做**：你把任务交给 AI 编程助手，它写代码，你负责检查和提交。平台要求提交参赛过程的记录（transcripts），用来证明东西确实是你这边做出来的，而不是从别处抄来的。

你不需要先买币、不用先懂 Solana 才能注册。注册之后再慢慢了解钱包和领奖。

## 两种赚钱方式

### 1. 赢赏金

挑一个你能做的赏金，按要求做出东西并提交。每个赏金按名次发钱：名次越高分得越多，也有不少赏金给前 50 名都发钱。奖金池从几百到上千美元不等，参加之前先看清截止时间和参赛要求。

### 2. 拉人（推荐）

每个账号都有自己的推荐链接，比如这份指南作者的：

**https://make.fun/r/sdjwe4wy**

别人通过你的链接注册，你就能赚钱。规则是这样的：

- 你拉来的人之后赢了奖，你拿他奖金的 **10%**，持续 **90 天**，分成期从对方注册那天起算，这 10% 是平台额外给的，不从他的奖金里扣。
- 目前注册本身没有现金奖励，第一次提交获奖也没有额外的固定奖励。推荐的收入来自那 10% 的分成。
- 只有真实参与的人才算数。注册了但从不回来、从不参加的人，给你带来 0 收入；刷出来的假账号不会被计入，还可能让你的推荐奖励被关掉。
- 自己的链接给自己用不算数，已经存在的账号也不算。
- 推荐链接可以放在你自己的帖子、个人主页或者项目 README 里，但不要发到不欢迎链接的地方。

所以拉人的正确姿势是：找真正可能感兴趣、愿意动手做东西的人，把这份指南连同链接一起发给他。

## 第一步：注册账号

1. 点开推荐链接：https://make.fun/r/sdjwe4wy
2. 用 GitHub 账号登录，或者用 Solana 钱包登录（二选一）。
3. 注册好之后，去个人页完善资料。领奖需要一个 Solana 钱包收 USDC，没有的话到时再建一个就行。

注册时注意：一个真人一个账号，不要替别人批量注册。

## 第二步：选一个赏金

打开赏金列表，先看这几样：

- **奖金池和名次**：第一名拿多少、前多少名有钱。
- **截止时间**：只接截止前你能做完的。
- **参赛要求**：每个赏金都有 requirements，写明了要交什么、怎么评、怎么提交。先读它，再动手。
- **适不适合你**：有的要写代码，有的只要写指南、做一张图。从自己能做的开始。

新手建议：先挑一个要求简单、截止时间宽裕的练手，熟悉一次完整流程比一上来就冲大奖重要。

## 第三步：做出来，并提交

1. 下载这个赏金的 kit（工具包），里面有规则说明和提交用的命令行工具。
2. 按规则把东西做出来。做代码的注意：程序要在规定的环境里跑通；做指南、图片的注意：文件格式和大小要符合要求。
3. 提交时需要附上你做东西的过程记录（transcripts）。如果你是用 AI 助手做的，它会帮你打包这些记录。记录的作用是证明东西是你这边原创的。
4. 提交后留意状态：如果检查没通过，按提示修好再重新提交，截止前都可以改。

## 第四步：领奖

- 结果公布后，获奖的奖金可以领到你的 Solana 钱包，币种是 USDC。
- 领推荐奖励也是一样，攒够起付金额（目前是 **0.25 美元**）就可以一次领走。
- 奖金累计到 **2,000 美元**以上需要补税务资料，平台会在领奖时提示。

## 常见问题

**我不会写代码，能参加吗？**

能。有些赏金不需要写代码（比如这份指南本身就是一个赏金的参赛作品）。另外你也可以让 AI 编程助手帮你写，你负责提要求、检查结果、提交。

**我需要先买加密货币吗？**

不需要。注册和参赛都不用先买币。领奖时才需要一个 Solana 钱包地址来收 USDC。

**推荐链接怎么用最有效？**

发给真正会对做赏金感兴趣的人，附上一句你自己的使用体验，比到处群发效果好得多。也可以把链接放在你自己的作品、帖子或个人主页里。

**多久能拿到钱？**

结果一般在赏金截止后一段时间公布，以赏金页写的时间为准。公布后按提示领奖，USDC 发到你的钱包。

**会被骗吗？**

奖金是提前锁在链上托管账户里的，不是某个人口头承诺。只要你在 make.fun 官网操作、按官方要求提交，就不用担心奖金不存在。任何让你先交钱、先转币的“捷径”都是骗局，不要理。
